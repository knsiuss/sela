# Pilot Eval

1. Baseline audit 7-14 days BEFORE go-live (every cancellation: entry channel, handler, empty-slot duration, refilled or not).
2. Go gates day-30: relative no-show reduction ≥25-30% vs own baseline, cancellation fill ≥40-50%, confirmation ≥60-70%, zero double-books, median time-to-fill <30 min.
3. Significance gate: N≥600 appointments + two-sample proportion test p<0.05, else extend to 60 days.
4. ROI pitch uses conservative independent numbers ($200 healthcare, $85 salon, $200 home-service per miss) — never vendor 135x claims.
5. One red gate = extend 60 days or pivot adapter. Never add features to fix a red gate.
