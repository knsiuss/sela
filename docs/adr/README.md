# Architecture Decision Records (ADR)

**Rules:**

- Numbered sequentially: ADR-001, ADR-002, ...
- **Immutable**: never edit an accepted ADR. If the decision changes, create a new ADR and mark the old one `Superseded by ADR-XXX`.
