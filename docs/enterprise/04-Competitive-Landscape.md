# 04 — Competitive Landscape

## 4.1 Mapping

- Direct (reminder + scheduling): Weave, NexHealth, Solutionreach, Artera/Luma/Phreesia/Doctible.
- Vertical salon: Fresha, Vagaro, Mangomint, Boulevard, Mindbody, Zenoti, Booksy, GlossGenius.
- FSM HVAC: ServiceTitan, Housecall Pro, Jobber.
- AI-native: Whippy, Sakari, Bland, Vellum, Booking Pro AI, Denti.AI/Brilo, Emitrr.

## 4.2 Profiles (fakta terverifikasi)

**Weave** — ~$249/mo Pro, Elite +scheduling/forms, setup $750 + $200 forms + $20/form. VoIP core, 20+ PMS, G2 4.6/426. Month-to-month. Limit: ganti phone system (2-4 minggu), no published SLA/export.
Source: PracticeSignal, Noshowcost.

**NexHealth** — ~$350-400/mo/location, Starter/Standard/Pro + Enterprise. Synchronizer API read/write (Dentrix, Eaglesoft, Open Dental, Curve). Month-to-month no cancel fee. G2 4.8/84. Keluhan: lag/sync, overpriced multi-site.
Source: PracticeSignal, GetDearDoc.

**Solutionreach** — list $199-249/mo yearly; reported $400-800 mid-market, $1k-2.5k enterprise + $1.5k implementasi. 21+ tahun, 35k customers, 500+ integrasi. Annual auto-renew, cancel 15 hari, 14 BBB complaints unanswered.
Source: solutionreach.com/pricing, noshowcost.com, PracticeSignal.

**Salon** — Fresha free + 20% new-client (min $6); Vagaro $25+/user; Mangomint $120 + $10/user (reported $165-265); Boulevard $176 list/$140 promo; Mindbody $79-599 + ~20% marketplace.
Source: BookingPro.ai, AgentZap, Booksy.

**HVAC** — Jobber $49 Core / $149 Connect (range $69-349); Housecall Pro $49 Basic / $129+; ServiceTitan custom, 4-5x Jobber, poor fit <5 techs.
Source: ServiceTitan compare, FieldPulse, TradeAppReviews.

**AI-native** — Emitrr $149; Booking Pro AI $0.25/mnt + $0.02/msg; Bland Build $299/mo (50 concurrent, 2k calls/day).
Source: Emitrr, BookingPro, Bland blog.

## 4.6 Moats & Barriers

- Integrasi dalam per PMS (bukan jumlah integrasi).
- Data percakapan + aturan slot per vertikal.
- Distribusi via asosiasi klinik / BSP WhatsApp / vendor PMS.
- Trust: SLA, export policy, audit log — yang bahkan incumbent tidak publish, jadi peluang diferensiasi.
