# 10 — Implementation Roadmap

## Phase 1: MVP (0-3 bulan)

- M1-2: WhatsApp/SMS connector, NLU tanggal/jam ID, Google Calendar + 1 PMS writer, flow book/reschedule/cancel + konfirmasi.
- M3: Reminder H-24/H-2, handoff manusia, dashboard dasar, pilot 3-5 lokasi.
- Exit criteria: 0 double-book pada pilot; recovery time terukur.

## Phase 2: PMF (3-9 bulan)

- Waitlist matcher, multi-staff/resource, deposit link, 1-2 PMS prioritas, analytics recovered revenue.
- 20-50 lokasi se-vertikal. Pricing freeze setelah case study.
- Exit criteria: reschedule completion tanpa manusia >60% [target, bukan fakta]; churn <5%/mo.

## Phase 3: Scale (9-24 bulan)

- Multi-location, voice overflow, recall campaign, partnership BSP/PMS.
- Target: 200+ lokasi atau ARR sesuai model pilot.

## Team

Awal: 1 product/engineer conversational, 1 integration engineer, 1 GTM/pilot owner, 1 part-time compliance/legal. Tambah setelah PMF.
