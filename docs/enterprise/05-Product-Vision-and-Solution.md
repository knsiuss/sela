# 05 — Product Vision and Solution

## 5.1 Vision

Resepsionis digital 24/7 yang menyelesaikan reschedule dalam 1 percakapan, bukan sekadar mengirim pengingat.

## 5.2 Value Prop

- Tangkap setiap balasan bebas kapan pun.
- Rebook ke slot live + update PMS/kalender + kirim konfirmasi.
- Isi yang kosong dari waitlist dalam menit.
- Ukur recovered revenue, bukan reminder terkirim.

## 5.3 Features

Must-have (MVP):
- NLU tanggal/jam informal + negosiasi 2-3 opsi slot.
- Availability real-time + hold slot + konfirmasi eksplisit (anti double-book).
- Cancel 1-tap + blast waitlist + update jadwal.
- Reminder H-24 + H-2 jam + auto-eskalasi jika tidak confirm.
- Human handoff + ringkasan percakapan.
- Dashboard: fill rate, no-show, recovery time, recovered revenue.

Should-have: multi-staff/resource (chair/room/teknisi), deposit/payment link, recall campaign, multi-location.
Nice-to-have: insurance verification, sentiment detection, outbound recall prediktif.

## 5.4 Multi-Channel

- Primer: WhatsApp (SEA) / SMS (US).
- Sekunder: Voice call untuk overflow + after-hours + waitlist call.
- Pendukung: IG DM, web chat. Satu orchestration, banyak connector.

Contoh flow klinik gigi dan HVAC emergency sudah ada di dokumen deep-research internal; jangan duplikasi di sini — refer ke Appendix C.

## 5.6 Differentiation

Bukan jumlah channel, tapi: 1 vertikal dalam + write-back real + recovery time tercepat + harga transparan tanpa setup $750 dan kontrak tahunan.
